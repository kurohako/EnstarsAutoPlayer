# EnstarsAutoPlayer V1
Experimental Android 11+ screenshot-based brightness detector and accessibility gesture prototype. No root required.
Not verified against game screenshots; may fail on protected screens, miss notes, or tap incorrect positions.
## Build
GitHub Actions > Build Android APK > workflow run > Artifacts > EnstarsAutoPlayer-debug-apk.
## Setup
Install debug APK, enable accessibility service in Android settings, adjust lane coordinates and brightness threshold, then Start.
Use on a controlled test screen first. Stop from the app or disable the service.
